# Rohan Vyavahare — Futuristic Developer Portfolio

Premium, cyberpunk-inspired personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, GSAP, and Lenis smooth scroll.

## Features

- Cinematic loading boot sequence
- 3D particle tech sphere, matrix rain, particle network background
- Glassmorphism UI, neon CTAs, custom cursor, scroll progress bar
- Hero typing effect, about stats counters, skills bars, project spotlight cards
- Experience timeline, achievements, services, testimonials
- Interactive terminal, AI recruiter chatbot, ambient audio toggle
- Day/night theme switch, EmailJS contact form
- Fully responsive layout

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## EmailJS setup

1. Copy `.env.example` to `.env`
2. Add your [EmailJS](https://www.emailjs.com/) credentials:

```
VITE_EMAILJS_SERVICE_ID=...
VITE_EMAILJS_TEMPLATE_ID=...
VITE_EMAILJS_PUBLIC_KEY=...
```

Without these, the contact form runs in demo mode (simulated success).

## Resume

Place your PDF at `public/resume.pdf` — linked as **Download Resume** across the site.

## Deploy

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to Vercel, Netlify, or GitHub Pages.

## Tech stack

- React 19 + Vite 8
- Tailwind CSS 4
- Framer Motion, GSAP, Lenis
- React Router, React Icons, EmailJS
